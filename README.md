## 📌 Project Overview

This project is part of my **30-Day Automotive Programming Journey**, where I am building small real-world automotive applications using **C programming**.

The objective of this project is to understand how basic C programming concepts can be applied to an automotive system to process inputs, implement decision-making logic, and generate meaningful system outputs.

### 🎯 Project Objective

The system is designed to:

- Accept relevant vehicle/system inputs
- Process the input using C programming logic
- Apply predefined decision-making conditions
- Generate an appropriate automotive system output
- Demonstrate how software logic can represent a real-world automotive feature

---

## 🧠 Concepts Practiced

This project helped me strengthen the following C programming concepts:

- Variables and data types
- `printf()` and `scanf()`
- Arithmetic operators
- Relational operators
- Logical operators
- Conditional statements
- `if`, `else if`, and `else`
- Functions
- Input validation
- Decision-making logic
- Structured programming
